## 9. FRESHER MISTAKES TO AVOID

1. Skipping DSA to build more projects.
2. Using AI to write code you cannot explain. Interviewers make you code live.
3. Ignoring aptitude. Many product companies filter on it first.
4. Learning many frameworks shallowly. Go deep on one stack.
5. Applying too late. Start on Day 3 and increase every Sunday.
6. Not revising. Use the 1-3-7 rule.
7. Memorizing solutions instead of recognizing patterns.
8. Long study days followed by zero days. Consistency beats intensity.
